# 时光机插件操作说明

适用：WinUI 3 桌面端。「时光机」是独立的受信模块（插件），定位「课堂录制 + 视频导出」；课堂记录、笔画数据与课件截图默认仅在本机处理。

## 1. 插件是什么

- 「时光机」不再是本体内置功能，而是与 AI 助教、PDF、解析几何等并列的独立模块，模块 ID 为 `inkcanvas.time-machine`（源码 `src/InkCanvas.Modules.TimeMachine`）。
- 插件只负责录制课堂板书与导出视频；本体的「墨迹回放」（在当前画布内从头重放一遍屏中墨迹）保留不变，与本插件互不依赖。
- 插件可以在「设置 → 模块与插件」中禁用或卸载。未安装、未启用时光机插件时，本体的画板、PPT 批注、墨迹回放、课堂工具等全部功能正常，工具栏不会出现录制入口。

## 2. 安装与启用

1. 时光机模块文件位于发行包模块目录；外部安装包解压到 `Modules` 目录后，在「设置 → 模块与插件」中查看其状态。
2. 模块开关下次启动生效；模块缺失、停用或启动失败时，相关命令入口会自动撤回，不影响其他模块。
3. 插件数据保存在其私有数据目录（`%APPDATA%\InkCanvas\PluginData\inkcanvas.time-machine` 或等价位置），与本体设置和画板存档分开存放。

## 3. 开始与停止录制

1. 打开画板，或进入 PPT 放映会话。
2. 在主工具栏（浮条「更多」面板 / 画板菜单）选择「开始时光机录制」。
   - 画板或 PPT 会话未打开时不能开始录制，会收到中文通知提示先打开画板。
3. 录制期间，工具栏上的同一命令变为「停止录制」；需要结束时直接在主工具栏选择「停止录制」即可。
4. 画板关闭时插件会自动停止并保存本次录制。
5. 本插件**没有**浮条录制状态显示，也**没有**暂停 / 继续录制：一次录制从开始到停止连续记录。

录制期间自动记录以下笔画级事件：

- 画板板书：落笔、擦除、清空、切页、背景切换、撤销 / 重做；
- 白板文件内容变化；
- PPT 放映中的批注变化与翻页；
- 课堂工具信号：点名、倒计时结束等。

## 4. 章节书签

- 自动书签：切页、清空、PPT 翻页、点名、倒计时结束时自动生成章节书签；相距极短时间内的相邻书签会合并。
- 书签随录制文件一起保存，用于录制列表中定位章节与按章节选择导出片段。

## 5. 录制文件

- 每次录制会话保存为**单个** `.icink` 文件（ZIP 容器），包内 `classroom.json` 标记格式 `inkcanvas-classroom` v1，包含：课堂元信息、章节书签、笔画级时间轴事件、板书历史数据与课堂截图（PNG）。
- 默认保存到插件私有目录下的 `Recordings\` 文件夹；也支持另存到任意路径，或从任意路径打开已有录制文件。
- 通过主工具栏的「时光机录制」命令可查看课堂录制列表（录制时间、时长、章节书签），并选择记录导出视频。

### 未安装插件时打开录制文件

本体在打开文件时会识别课堂录制格式。若探测到 `.icink` 课堂录制文件而时光机插件未安装或未启用，会弹出中文提示：

> 此文件是时光机课堂录制文件，需要安装并启用“时光机”插件才能读取。

提示不会导致崩溃，也不会把录制文件当作普通画板误读。普通画板 `.icink` 存档与 `.pdf` 等既有文件的打开方式不受影响。

## 6. 导出 MP4 视频

1. 在录制列表中选择目标记录，打开导出入口。
2. 调整导出参数：

| 参数 | 可选范围 / 预设 |
| --- | --- |
| 分辨率 | 1920×1080、1280×720、源尺寸，或自定义宽高（320–3840） |
| 倍速 | 0.5×–8×（默认 1×，界面提供 1× / 2× / 4× 等档位） |
| 帧率 | 1–120 fps（默认 30） |
| 码率 | 100k–100M（默认 4M） |
| 仅板书 | 开启后只导出板书笔画，不含 PPT 截图背景 |
| 显示光标 | 在导出帧上绘制最近一笔末端的高亮圆点（可关闭） |
| 显示章节信息 | 在画面上叠加最近书签的时间 / 页 / 摘要（可关闭） |

3. 可按章节书签选择导出片段：自动填入该章节开始时间，结束时间取下一章节或录制末尾，仍可手动微调。
4. 导出在后台进行，显示进度，可取消；导出期间可继续书写。成功或取消后清理半成品文件。
5. **本插件不录制、不合成讲解音频**：MP4 为纯视频，不含音轨。

## 7. 本地处理与隐私

- 课堂记录、笔画数据、课件截图与导出文件均保存在本机，不产生网络上传；导出文件仅写入用户选择的本机路径。
- 插件私有目录与本体数据目录分开，卸载插件时其录制数据按插件数据目录规则处理。
