# 教学闭环操作说明（教师版）

适用：WinUI 3 桌面端。课件存档、名单、积分、板书与课堂记录默认保存在本机；配置 AI 服务后，所选题目截图、墨迹和相关题目上下文会发送到配置的服务端点。

## 1. AI 讲题

未配置 `AI_ENDPOINT` 时为演示模式，界面持续标明所显示的固定示例，不代表对所选题目的真实识别。连接实际服务需按 [AI 配置](ai-magic-lasso.md#3-依赖与环境变量) 设置兼容端点。

1. 用「选择」工具框选题目（可多次框选题干、图形、补充条件）。
2. 点击浮条上的「AI」识别；浮窗显示识别结果与讲题方式。
3. 讲题方式四选一：
   - **只给提示**：只出现思路引导，不出现答案；
   - **分步引导**（课堂默认）：一次只展示一步，点「下一步」才继续；
   - **完整解答**：展示完整推导与结论；
   - **教师解析**：面向讲解过程的说明。
4. 分步模式下，后续步骤与最终答案不会提前出现在界面中；投屏时默认不泄露答案。
5. 框选错误可单独删除某个选区，或点该选区的「↻」重新识别，不影响其他选区。
6. 识别结果可「贴回白板」，公式保留 LaTeX 源，可双击再次编辑；图形标注为独立图层。

## 2. 课件导航与批注

1. 进入 PowerPoint 放映后自动联动，覆盖层可直接批注。
2. 打开「课件导航」可看到缩略图，按「全部 / 仅批注 / 收藏」筛选并跳页。
3. 批注按幻灯片唯一 ID 关联：插页、删页、调序后不会串页。
4. 四角翻页器支持翻页、批注开关、位置循环与收起。

## 3. 随堂练习

1. AI 识别后点「基础变式」或「提高变式」生成变式题。
2. 在预览对话框中可修改题干与答案，确认后才进入画板。
3. 点「开始练习」：自动新建练习页（不覆盖原题）、贴入练习卡片、切换到练习场景并启动倒计时。
4. 倒计时结束发出练习结束信号；若「时光机」插件正在录制，板书快照与「练习结束」章节书签由插件生成，可在插件的录制列表中按书签跳转。

## 4. 课后讲义导出

1. 打开「讲义导出」，选择「全部 / 仅批注 / 选中页」。
2. 可预览首页并勾选页面；导出为 PNG 与 PDF（本地生成，修改不到原课件）。
3. 导出在后台执行，可取消、失败可重试；导出期间可继续书写。

## 5. 历史内容复用

- **例题库（已接入界面）**：从浮条「展开更多 → 课堂工具 → 例题库」打开；窗口内可按关键词/课题/知识点检索、清空条件、查看题目/答案/订正详情并删除条目。当前「收藏为例题」写入按钮尚未接入 AI 浮窗，新例题暂需通过服务层写入。
- **课堂资源包（已接入界面）**：从浮条「展开更多 → 课堂工具 → 资源包」打开；窗口可打包课件、批注、练习等课堂文件，「打开资源包」解包到 `%APPDATA%\InkCanvas\bundles\<时间戳>`，解包不覆盖已有文件。时光机录制文件保存在插件私有目录，不纳入资源包枚举。

## 6. 配置开关（管理员/高级）

`Settings.json` 的 `features` 节点可关闭对应能力：
- `enableExampleLibrary=false`：例题库不可新增/删除，检索为空（已存数据仍可读取）。
- `enableResourceBundle=false`：不可打包课堂资源包（已有包仍可解包）。

旧配置缺少该节点时按全部开启处理。
