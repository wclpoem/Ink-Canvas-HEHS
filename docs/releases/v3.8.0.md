# Ink Canvas WinUI 3 v3.8.0

本版新增原生文稿库和资源管理器预览插件，完善白板、屏幕批注的存档与备份，并将 AI 功能独立分包。

- 文稿库支持文件夹导航、搜索、排序、收藏、最近使用、逐页预览、重命名、移动和副本，接通白板打开与保存入口，采用 WinUI 3 标题栏、Mica 和深浅色主题。
- 新增轻量 x64 资源管理器扩展，提供 `.icink` 缩略图和首页预览。扩展通过 Windows 隔离宿主按需读取封面，独立安装。旧文稿用新版重新保存后可生成封面。
- 保存与备份支持自定义默认路径、课程与班级信息、文件名模板、定时备份、退出自动保存及保留份数。新增截图与墨迹单页存档，可单独启用普通批注模式，屏幕外墨迹保留为可编辑对象。
- AI 助教独立为原生插件，并增加与文稿库、PDF、解析几何的适配接口。可在“设置 → 保存与备份”手动开启保存后自动命名与描述，或在文稿库中执行一次分析。
- AI 存档分析支持原分辨率 PNG、大范围批注总览与高清局部、长白板重叠分页及多图分批分析。白板实际重命名并内嵌描述，PDF 和解析几何的名称建议与描述保存到相邻 `.ai.json` 文件。模型调用失败时保留原存档。
- 恢复 PPT 放映四处翻页辅助控件的布局与闲时透明度效果，调整底部控件与主工具栏的对齐，补充放映中鼠标模式下的墨迹隐藏设置。
- 默认画笔颜色适配深浅背景，图标统一为项目随附的 Fluent System Icons，支持 Filled/Regular 风格。
- 修复设置右侧底部固定空白条和滚动内容提前裁切，优化页面末尾留白及搜索定位。

## 下载与安装

下载 `InkCanvas-WinUI3-3.8.0-win-x64.zip`，解压后运行 `InkCanvas/InkCanvas.exe`。完整包包含文稿库 1.0.1、AI 助教 1.1.0、PDF 1.0.7、解析几何 2.0.4 和屏幕跟随 1.0.2，另附各插件独立安装包。

原生模块 ZIP 解压到程序的 `Modules` 目录，并与本次主程序配套使用。资源管理器插件解压后使用 64 位 PowerShell 运行 `Install.ps1`，按当前用户安装，可运行 `Uninstall.ps1` 卸载。

首次使用需要 .NET 10 x64 运行时，旧版导入插件需要 .NET 10 Desktop Runtime。Windows App SDK 运行文件随主程序提供。

## 自动更新

应用内自动更新可识别本版正式发行包。更新器先访问 GitHub 官方源，再依次使用配置的镜像源，并核对发布文件的大小和 SHA256。`SHA256SUMS.txt` 同时列出主程序与独立插件包的校验值。

升级保留用户设置、文稿和外部插件。已安装的可选模块随主程序更新，新模块可从本次 Release 下载单独安装。
