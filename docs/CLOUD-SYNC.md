# 云同步插件

云同步以独立原生模块提供，安装并启用后在设置侧栏的“插件设置”中添加“云同步”。主程序与发行包内的服务地址默认留空，由学校或服务管理员单独提供。

## 账号与自动备份

填写 HTTPS 服务地址和账号密码登录。首次注册需输入管理员发放的一次性邀请码，密码至少 12 个字符。登录后开启“自动备份白板到云端”，插件会在白板存档完成后后台上传，并按设定间隔保存有变化的白板。

传输使用文件流和 SHA-256 校验，上传失败保留队列并定时重试。云端按文件内容保留版本，重复文件去重。点“查看云端文稿”后可恢复独立副本至默认存档目录下的 `CloudDownloads`。

## 个人配置

“同步个人书写和外观偏好”同步外观、画笔、手势、形状识别、演示偏好与功能开关。配置通过版本号检测跨设备冲突，发生冲突后可选择恢复云端偏好，或确认以本机偏好更新云端。

个人偏好可以单独开启同步。切换账号后，自动备份和偏好同步需要重新开启，待上传队列同时清空。

服务端只接受白名单中的偏好分组。API 密钥、AI 连接、设备路径、显示器、名单、插件私有数据和开机行为保存在本机。登录刷新令牌存储于 Windows 凭据管理器，插件状态 JSON 保存同步队列和进度。

## 学校批量部署

管理员向每台设备的 `%PROGRAMDATA%\InkCanvas\cloud-policy.json` 分发以下结构，并为文件设置合适的系统访问权限。

```json
{
  "serviceUrl": "https://sync.example.invalid/",
  "syncIntervalMinutes": 5
}
```

部署文件提供服务地址与同步间隔，教师仍需使用各自的账号登录。通过服务端管理员接口批量生成邀请码，分配个人账号。发布包中不附带部署文件、账号或凭据。

## 自托管

服务端源码位于 `server/cloud-sync`，提供 FastAPI、私有对象存储、数据库和容器部署示例。生产地址、Bucket 名称、账号与 TLS 配置由部署者在仓库外维护。
