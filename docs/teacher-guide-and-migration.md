# 教师操作说明与历史数据兼容说明

- 分支：`统一板书对象模型并完善AI课堂教学闭环`
- 适用版本：合并云端 v3.10.0 后的本地优先版本

## 1. 教师操作说明

### 1.1 浮动工具栏

- `Alt+B` 打开/关闭主展板；`Alt+N` 拉出/收回板中板（单实例，不嵌套）。
- 笔/荧光笔/橡皮/选择/图形/清空/撤销/重做；`Alt+Q` 鼠标穿透，`Alt+V` 收纳到屏幕侧边。
- 「AI 助教」打开浮窗；「打开板书时光机」进入录制回放；「更多设置」含课堂工具、倒计时、抽奖、课件导航、PDF、设置等。

### 1.2 AI 助教

- 框选内容后点「AI 识别」：分步引导/完整解答/教师解析可选；投屏模式下默认降级为分步，避免提前泄露答案。
- 「基础变式 / 提高变式」：生成变式题 → 预览（题目/答案/知识点可改）→「开始练习」新建练习页并可启动倒计时。
- 「整理板书」：显示“原始内容 | 整理结果”，低置信度与疑似笔误有标记；可全部采用、仅采用选中块、或替换原板书（一次撤销）。
- 「AI 书写」：按自然语言写公式/句子/词语/古诗/总结；写入为**可编辑原生对象**（非图片）；公式保留 LaTeX 源，双击可改。
- 连续修改：字号/两列/只保留公式/移到另一板等，优先修改已选中对象，不重新生成。
- 「贴回白板 / 收藏例题」：贴回为可编辑对象；例题库支持“再讲一次 / 贴回白板 / 编辑订正”。
- 失败会保留指令与预览，可重试；不会清空原始板书。

### 1.3 板中板

- 定位为临时演算/补充讲解/练习/AI 暂存区；独立内容、视口与撤销栈；收回保留内容，再拉出恢复。
- 支持「贴到主展板」（复制，不修改子板）与「取消分组」「选择/拖动/缩放/删除」。

### 1.4 课堂闭环

- 讲题：框选 → AI 分步讲题 → 图形标注/公式纠错 → 教师确认 → 可编辑贴回 → 收藏例题（记录会话/课件页/对象组）。
- 练习：AI 变式 → 预览编辑 → 新练习页（原生对象）→ 倒计时 → 结束自动截图快照+「练习结束」书签 → 再来一题/收题/导出。
- 总结：选择重点 → 整理为可编辑总结 → 写入「课堂总结」页（原页保留）→ 讲义导出/回放片段。

### 1.5 时光机

- 「开始时光机录制」记录主/子板笔画与 AI 对象；停止后可回放、章节定位、导出视频。
- 同一时间点无论从头播放、直接定位、倒退重放还是倍速到达，画面一致；回放不请求模型。
- 启动时若检测到未完成录制，会提示「恢复/放弃」；恢复的会话名带“（已恢复）”。

### 1.6 个人预设与资源包

- 「课堂工具 → 编辑场景」可保存个人预设：工具勾选、倒计时，以及笔色/背景/模板/AI 指令/练习时长（仅保存，不改变工具行为）。
- 「资源包」可打包白板存档、课件批注、例题库、时光机录制；解包同名自动追加后缀，不覆盖。

### 1.7 恢复与清理

- 启动自动清理过期临时文件（`.tmp`、恢复暂存目录等）；课堂会话默认保留 90 天（最近 20 条永不自动删）。
- 白板文件默认保存为 `.icink`；建议开启自动存档。

## 2. 历史数据兼容

| 数据 | 兼容策略 |
|---|---|
| Board v4（含 PageId/TextObjects/FormulaObjects/Viewport/SideBoard/Blob） | 读取 v2/v3/v4；缺字段按默认生成（PageId 运行期生成并随保存写回）；未知字段忽略 |
| 旧单页 JSON（无 ZIP 签名） | 仍按旧单页读取；无媒体时保存可降级回旧格式 |
| 旧 AI 卡片（PNG + AiPasteMetadata） | 保留读取/双击编辑/重命名兼容；新写入不再产生图片对象 |
| 时光机会话 schema=2 | 读取兼容；对象缺 transform 时回退 identity（外观可能与当时不同，已在回放标记） |
| 旧课堂会话/录制 | 保留 `.snapshot.json`/`.journal` 恢复；恢复合并后写正式会话并补“（已恢复）” |
| 设置 JSON | 新增字段均为可选（archive/hotkey/sideBoard/features.unifiedContext/presetsVersion 等），缺失回退默认 |
| 课件批注（PPT/PDF） | 继续按 slideId/PDF 批注文件独立保存，格式未改 |

## 3. 备份与回滚

- 合并前已建备份分支：`备份/合并云端v3.10.0-前`；合并提交 `a27a725`。
- 文件级备份：`<file>.bak`（会话/设置等原子写入处）。
- 功能级回滚：`features.unifiedContext=false` 回退旧上下文路由；`features.nativePractice` 可回退练习写入路径；旧 PNG 卡片路径保留。
- 若新版本读取旧文件出现异常：优先复制原文件后用旧版本打开，或从 `.bak`/备份分支恢复。
