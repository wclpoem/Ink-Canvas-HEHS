# 更新

Ink Canvas 从 `QiXinia/Ink-Canvas-HEHS` 的 GitHub Releases 获取公开稳定版列表。更新服务不需要 GitHub 登录凭据。列表排除草稿版和预发行版，并选择名称包含 InkCanvas、WinUI、x64 的便携 ZIP。

## 下载验证

更新确认、版本列表及检查结果采用独立 WinUI 3 窗口。版本说明通过 Markdig 解析后由共用的原生控件渲染，支持标题、强调、嵌套与任务列表、引用、代码、链接、表格和图片。当前版本及旧版本在列表中显示说明并禁用更新操作。说明保持完整，可滚动与选择文本，浅深色主题随窗口设置应用。链接点击交给系统浏览器，支持 HTTP、HTTPS 和邮件地址。

更新包必须带有 GitHub Release 提供的 SHA256 digest，或同一 Release 中 `SHA256SUMS.txt` 对应文件名的校验值。下载过程中同时检查发布的文件大小，只有长度与 SHA256 均匹配时才会将 `.partial` 文件移为可安装 ZIP。API、下载内容、超时和校验失败会继续尝试下一个 HTTPS 来源。传输每获得 64 KiB 数据才续期二十秒的进度超时，避免持续返回少量数据的慢连接阻塞切源。

主程序更新、插件仓库列表、校验清单和安装包共用每批 3 个源的并发检测。第一批同时探测 GitHub 官方源及下列前两个镜像，全部失败后再探测后三个镜像。版本列表和校验清单采用最先完成内容校验的响应。下载采用最先返回成功响应且大小符合发布信息的源，并复用该连接传输文件。选定后取消其余探测，释放未使用的响应。下载中断或 SHA256 校验失败时，继续尝试该批剩余源，再切换下一批。

每个镜像前缀后直接拼接包含 `https://` 的完整 GitHub 原始链接。

1. `https://ghfile.geekertao.top/`
2. `https://github.dpik.top/`
3. `https://gh-proxy.com/`
4. `https://fastgit.cc/`
5. `https://gh.acmsz.top/`

例如 `https://ghfile.geekertao.top/https://github.com/QiXinia/Ink-Canvas-HEHS/releases/download/v3.7.1/SHA256SUMS.txt`。原 `gh-proxy.org`、`ghfast.top` 已移出默认源。

匿名 GitHub API 被限流或全部 API 镜像不可用时，更新器继续读取公开 Releases 页面及其附件清单。若镜像仅支持附件下载，再通过官方最新稳定版 `releases/latest/download/SHA256SUMS.txt` 提取便携包文件名、版本号与 SHA256，此时版本列表只显示获取到的最新稳定版。页面链接限制为同一 GitHub 仓库，排除预发行版。下载始终核对完整 SHA256。

连接与读取停滞会记录明确的中文超时原因，并继续切换下一源。读取额外采用计时等待，即使底层网络流未及时响应取消标志，也会结束该次尝试。用户主动取消或程序退出时终止重试。失败详情写入 Ink Canvas 应用日志。

## 静默安装

“自动检查更新”和“静默更新”启用时，更新器每六小时检查一次。静默更新按设置的起止时间执行，起止时间相同表示全天。安装前还要求画布没有批注和活动笔画，没有打开的白板、文档或其他相关窗口，并且系统输入空闲至少一分钟。条件未满足时保留更新并继续等待。更新失败会在十五分钟后重试。

静默更新开启时，时段外继续等待。静默更新关闭时，自动检查会显示版本说明并等待确认。手动“版本列表”也由用户选择版本和确认。手动安装会保存当前画布和应用设置，然后关闭主程序。

## 文件替换与恢复

便携 ZIP 解压到用户本地应用数据目录下的唯一暂存目录。更新辅助进程位于暂存目录，在确认主进程退出后替换程序文件。已安装的可选模块随主程序更新，未安装的可选模块不会被添加。`Plugins`、`PluginData`、设置、自动保存、`.icink` 文档和其他未列入 Ink Canvas 更新清单的文件会保留。

更新器记录本次托管文件清单，只删除前一次清单中的旧程序文件。正式替换前会备份将被覆盖或删除的文件，并写入回滚日志。若更新进程在替换期间失败或中断，下次运行同一更新计划时先恢复该日志，再重试更新。

包和安装暂存位于 `%LOCALAPPDATA%\InkCanvas\Updates`。技术日志位于 `%APPDATA%\InkCanvas\Log.txt`。

## 存储管理与进度

设置的“存储与缓存”页面显示更新缓存、配置临时文件、用户配置和其他用户数据的占用、最近配置保存时间、备份状态及目录入口。统计与清理在后台执行，页面参与设置搜索。

同一 SHA256 的更新包复用一个缓存目录，每次复用前重新核对大小与 SHA256。下载、暂存和外部安装进程使用独占租约，清理会跳过正在使用的目录。回滚日志始终保留，待安装计划和近期创建的计划受到保护。默认每日清理一次超过 7 天未使用的更新缓存，可关闭自动清理或将保留时间设为 1、3、7、14、30 天。“清理未使用的缓存”会立即回收符合条件的闲置包，同时清理超过一天的已知配置写入残留文件。

配置内容未改变时跳过磁盘写入。写入采用唯一临时文件与原子替换，`Settings.json.bak` 保留上一份有效配置，主配置损坏后自动从备份恢复。清理仅处理托管缓存与已知临时文件，用户配置、插件数据、墨迹、截图和更新前画布备份继续由其各自的保存入口管理。扫描和清理跳过链接目录。

更新期间，设置底部持续显示检查、下载、SHA256 校验和文件准备阶段，下载进度包含百分比、已下载与总大小、平均速度和当前来源。缺少总大小或处于校验、准备阶段时显示不定进度。切换页面或重新打开设置会继续显示当前任务，退出安装前可取消传输与准备。安装文件替换在主程序退出后由独立更新进程完成。

2026-11-20 缓存与进度改动通过 782 项域测试和 10 项 WinUI 原生检查。检查使用隔离配置、模拟下载流和安装目标，覆盖镜像进度、页面切换、重新打开设置、取消、实际清理入口、配置保留与外部更新进程租约。报告位于 `artifacts/storage-update-tests` 和 `artifacts/storage-update-final`。

## 仓库验收

以 GitHub 仓库发布的 `v3.5.0` 真实 ZIP 在隔离目录执行了完整流程，涵盖版本列表识别、GitHub 下载和 SHA256 校验、GitHub 断连后的镜像列表及 ZIP 下载、ZIP 暂存、外部辅助进程替换、用户插件和 `.icink` 保留，以及更新后程序启动。镜像访问在部分轮次返回 403 或出现 TLS/连接超时，成功轮次的真实包已通过 SHA256 校验。

2026-11-20 更换镜像后的验收使用仓库 `v3.7.1` 的真实更新包，大小为 42,431,373 字节。GitHub 官方源下载及屏蔽 GitHub 直连后的 `ghfile.geekertao.top` 镜像下载均通过 SHA256 校验，校验值为 `2f5c28a052d39bf6d1f4c83625f25e511abfe9f20f8ebdf3499cdcca57b85d7a`。屏蔽直连时，版本 API 在前两个镜像失败后继续从 `gh-proxy.com` 获取列表。单元测试共 775 项通过，覆盖默认源顺序、API 与页面回退、仅附件镜像、主动取消，以及底层流不响应取消时的超时切源。


## MSI 安装版更新

从 3.10.0 起，Release 同时提供 MSI 和 ZIP。程序检测安装目录的 .inkcanvas-msi 标记，安装版仅选择匹配版本的 MSI，便携版选择 ZIP。MSI 在下载及暂存时核对 SHA256，并校验产品名称、稳定 UpgradeCode、安装范围和版本。退出前保存画布，辅助进程等待主程序结束后调用 Windows Installer 执行无重启升级。Windows Installer 的事务处理负责文件回滚，结果和日志写入当前更新暂存目录。安装说明见 INSTALLATION.md。
